# 服务器设置

**服务器** 页点一台服务器 → **编辑**，设置分成几块：基本、价格与到期、流量、地址与地区、转发方式，不常用的通知和高级选项折叠在最下面。

## 基本

- **名称**、**分组**：分组随便填，例如「香港」「家宽」「主力」，已用过的分组会列在输入框下面，点一下就能填上。服务器列表上方可以按分组筛选，状态页也可以按分组显示，见 [状态页](./status-page.md)
- **公开备注**：显示在状态页的服务器名称下面，最多 200 字
- **私有备注**：只有管理员看得到
- **公开显示**：关闭后这台服务器不出现在状态页上，和 **设置 → 状态页 → 显示哪些服务器** 是同一个设置
- **离线通知**：服务器掉线、恢复时各推一条，需要先在 **设置 → 通知** 打开通知；其他事件在下面的 **通知** 里单独设置

## 价格与到期

填 **价格**、**货币**、**付款周期**（例如「1 年」「3 月」）和 **到期时间**。到期时间过了以后，面板按付款周期自动顺延到下一次，快到期时按 **设置 → 通知** 里的到期提醒推送。价格留空或填 0 表示免费；付款周期和到期时间要一起填。

续费后只想改价格或到期时间时，在服务器上点 **价格与到期**，会打开一个只有这几项的小窗口。

状态页默认不显示价格，在 **设置 → 状态页** 打开 **显示价格** 后才显示，例如 `¥151.2/年`。

## 流量额度与校正

- **每月额度（GB）**：留空不限。设了以后，服务器列表上显示「已用 / 额度」，快用完时变色；状态页上有额度进度条
- **计算方式**：上下行相加、取较大值、只算上行（服务器发出的）或只算下行（服务器收到的），按服务商的计费方式选
- **每月重置日**：1–31，默认 1 号。本月流量从这一天 0 点开始算（按面板所在时区）；月份没有这一天时（例如 31 号遇到 2 月）按月底

服务器列表和状态页的「本月」流量都按这里的重置日计算。

**流量校正**：面板统计和服务商面板上的用量对不上时，展开 **流量校正**，填服务商显示的本期上行、下行（GB），保存后本期流量就改成这个数，之后照常累加。只改其中一项时另一项留空。校正只对本期有效，到下一个重置日自动失效。

::: tip
3.9.4 之前的 agent 会把 Docker、虚拟网卡的流量也算进去，容器重启时还可能把开机以来的总流量重复加一遍，导致「本月流量」偏大很多。升级 agent 后不会再这样；已经多算的部分用流量校正改回来即可。
:::

## 地址与地区

至少填一个 **IPv4**、**IPv6** 或 **域名**，这是这台服务器自己的地址（不是面板的地址），分享节点、对接中转时用它。**国家/地区** 默认按地址自动识别，也可以手动选，见 [状态页 → 地区](./status-page.md#地区)。**可用端口** 是面板分配给转发和节点用的端口范围。

## 转发方式

- **agent**（推荐）：服务器安装 agent，支持全部功能，见 [安装 agent](./agent.md)
- **nftables**：不装 agent，面板通过 SSH 下发 nftables 规则，只能做纯端口转发；选它以后在下面填 SSH 主机、用户名和认证方式

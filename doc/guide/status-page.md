# 状态页

状态页是一个不用登录就能打开的页面，地址是 `面板地址/status/`。它展示每台服务器是否在线、近 30 天的可用率、CPU / 内存 / Swap / 磁盘、负载、TCP / UDP 连接数、实时网速和本月流量，以及到各测试点的延迟和回程线路，适合发给用户或挂在群公告里。

状态页**不会**显示服务器 IP、端口、密钥、用户、节点和协议，也不显示系统版本、内核版本和 agent 版本。回程只显示线路名（例如 CN2 GIA、9929、CMI），不显示经过的每一跳。

## 开启

在 **设置 → 状态页** 打开 **开启状态页** 后保存，登录页下方会出现“查看服务器状态”入口。默认是关闭的，关闭时访问 `/status/` 只会看到“状态页未开启”。

| 设置 | 说明 |
|------|------|
| 标题 | 留空时使用应用名称 |
| 显示网速和流量 | 默认开启；关闭后不显示实时上下行速度和本月流量，详情页也没有网速图 |
| 显示系统信息 | 默认关闭；开启后显示每台服务器的系统、架构、虚拟化方式和 CPU 型号。内核版本始终不公开 |
| 显示到期日 | 默认关闭；开启后，设了到期时间的服务器会显示到期日期（不显示价格） |
| 显示哪些服务器 | 取消勾选的服务器不会出现在状态页上 |

服务器名称以国旗 emoji 开头（例如 `🇭🇰 香港 HKT`）时，状态页会按地区分组，服务器列表上方可以按地区筛选，也可以输入名称筛选。

服务器默认以卡片显示，右上角可以切换成 **列表**（表格），浏览器会记住选择。右上角的月亮 / 太阳按钮切换深色和浅色。

延迟和回程来自 **设置 → 延迟测试点**，卡片上最多显示 3 个测试点（服务器设置了固定显示的测试点时用那几个）。回程每天检测一次，检测过才显示；双栈服务器的 IPv6 回程与 IPv4 不同时，后面多一个 `v6` 标签。见 [延迟与回程](./latency.md)。

## 服务器详情

点服务器卡片（或列表的一行）进入详情页 `面板地址/status/node/<序号>`，顶部是当前的 CPU、内存、Swap、磁盘、负载、连接数、网速、本月流量和到期日，以及各测试点的延迟、丢包和回程；下面可以看近 1 小时、6 小时、24 小时、7 天的历史：
CPU / 内存 / Swap / 磁盘使用率、网速、负载、TCP / UDP 连接数和进程数，以及各测试点的延迟（断开处为超时）。
每个点是一段时间内的平均值（1 小时为 10 秒，7 天约 28 分钟）。

- 历史能看多久取决于 **设置 → 服务器与监控** 里的监控数据保留天数（默认 7 天）。
- 序号是服务器在状态页上的位置，不是面板里的编号；隐藏的服务器没有详情页。
- Swap、进程数以及系统信息需要节点 agent 3.9.0 及以上；旧 agent 照常工作，只是不显示这几项。

## 主题

状态页的外观由**主题**决定，在 **设置 → 状态页 → 主题** 里管理，操作立即生效，不需要点保存：

- **FLYX 默认**：内置主题，随面板一起升级，不能删除。
- **从 GitHub 安装**：填主题仓库地址（如 `https://github.com/作者/仓库`），面板下载该仓库最新 release 里的 `theme.tar.gz`。
- **上传 theme.tar.gz**：面板连不上 GitHub 时，先在电脑上下载主题包再上传，最大 32 MiB。
- **使用**：切换到这个主题；**检查更新**：有新 release 时更新到最新版本；**删除**：正在使用的主题被删除后自动换回内置主题，它的设置也一并删除。
- **设置**：主题提供了可调整的选项时才显示（内置主题暂时没有）。只保存改过的项，**恢复默认** 清空全部；保存后状态页刷新即生效。设置对访客公开，不要填写密码一类的内容。

安装的主题保存在面板数据目录的 `themes/` 下（Docker 部署即 `sqlite_data` 卷），升级或重装面板不会丢失。

::: warning 只安装信任的主题
主题是运行在面板域名下的网页，能读到同一浏览器里的面板登录状态。只安装你信任的作者发布的主题。
:::

monitor 的主题不能直接安装：FLYX 主题使用 FLYX 的状态接口，需要按 [主题开发](./status-theme-dev.md) 适配。

## 可用率怎么算

面板每分钟检查一次每台服务器是否在线，记录保留 31 天。

- **24 小时 / 30 天**：这段时间内服务器在线的比例。
- **每天一格**：离线不超过 5 分钟为绿色，5–30 分钟为橙色，超过 30 分钟为红色，没有记录为灰色。一次重启或很短的断线不会让当天变红。

可用率从升级到带状态页的版本后才开始记录，之前的日子显示为灰色。日期按面板服务器的时区划分（安装脚本默认 `Asia/Shanghai`）。

页面每 10 秒自动刷新一次。实时数据（CPU、内存、网速等）来自 agent 上报，超过 3 分钟没有上报就不再显示。

CPU 核心数和内存、磁盘的已用 / 总容量需要把 agent 升级到同一版本或更新版本；旧 agent 照常工作，只是不显示这几项。磁盘统计的是根分区 `/`。容器里运行的 agent 读到的通常是宿主机的核心数和内存，不是容器的限制。

## 延迟

服务器设置了 [延迟测试点](./latency.md) 时，卡片上显示最多 3 个测试点近 1 小时的延迟和丢包（优先显示固定的测试点）。只显示测试点的名称，不显示测试地址和错误信息。

## 安全

- 状态页只能读取，没有任何会改动面板的操作；关闭后接口只返回“状态页未开启”。
- 接口只接受 GET / HEAD 请求，所有访客拿到的是同一份缓存好的结果，每 5 秒最多重新查询一次数据库。大量请求的开销和访问静态文件差不多，刷新不会拖慢面板。
- 响应带 `Cache-Control: public, max-age=5`，面板放在 Cloudflare 等 CDN 后面时，重复请求大多由 CDN 挡下。
- 服务器名称会原样公开，不要在里面写 IP 或敏感信息；不想公开的服务器在“显示哪些服务器”里取消勾选。

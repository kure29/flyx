导入节点 ​

在 节点 页点 更多 → 导入节点，可以把不是面板部署的节点（脚本搭的、没装 agent 的机器、机场节点）加进来，用来对接中转和加入订阅。转换规则参考 Sub-Store：所有格式先转成 Mihomo（Clash Meta）节点格式保存，再按订阅格式输出，参数不会丢失。

支持的输入 ​

  • 分享链接（每行一个）：ss://（含 obfs / v2ray-plugin / shadow-tls 插件）、vmess://（v2rayN 格式）、vless://（含 Reality、WS、gRPC、H2、XHTTP）、trojan://、hysteria2:// / hy2://、tuic://、anytls://、socks5://
  • base64 订阅内容
  • Clash / Mihomo 配置（读取 proxies）
  • sing-box 配置（读取 outbounds）
  • Surge / Loon 节点行，例如 名称 = snell, 1.2.3.4, 6160, psk=..., version=4
  • 订阅文件：点 选择订阅文件，内容可以是上面任意一种，最大 5MB。打开 存为订阅源 会存成文件订阅源，以后重新上传就能更新
  • 订阅地址（https://...）：面板服务器会以 Mihomo 的身份去下载，拿到的通常是参数最完整的 Clash 配置。打开 定时同步（默认打开）会存成 订阅源，按时更新；关掉则只导入一次

手动填写 ​

没有现成的链接时，在导入窗口顶部切到 手动填写，选协议后逐项填写地址、端口、密码 / UUID，以及 TLS / Reality、传输方式（TCP / WebSocket / gRPC）等参数。支持 Shadowsocks、VLESS、VMess、Trojan、Hysteria2、TUIC v5、AnyTLS、SOCKS5。名称留空时用“地址:端口”。填好的内容会按分享链接的格式保存，和粘贴链接导入的节点完全一样。

标签 ​

节点多了可以打标签区分，比如“出站”“落地”“香港”：

  • 导入或手动填写时可以直接填标签（存为订阅源时不填）
  • 已有的节点：点击节点 → 标签；面板自建的入站也可以打标签
  • 批量：更多 → 批量操作，选中节点后点 标签，会替换选中节点原来的标签
  • 列表上方的 全部标签 下拉框按标签筛选，搜索框也能搜标签

标签只用于在面板里区分和筛选，不影响订阅和分享。每个节点最多 10 个标签，每个不超过 20 字，不能包含逗号。

说明 ​

  • 暂不支持 WireGuard、SSR、Hysteria v1 等类型，导入时会逐条提示
  • 经中转连接时，原节点用域名连接的，会自动把域名保留为 TLS SNI 和 WebSocket Host；Hysteria2 端口跳跃只在直连线路上保留
  • 面板不会部署、修改这些节点，也没有流量统计、白名单、换密钥等功能
  • 原节点的地址或参数变了，点击该节点 → 编辑，修改地址或粘贴新的链接替换参数，相关中转会自动指向新地址
  • 勾选“只通过我的转发访问”后，订阅和分享中不再包含直连线路，只放你自己机器上的中转线路（该节点没有中转时就不会出现在订阅里）
  • 删除只会删除面板里的记录和相关中转，不影响原服务器
  • 同一个地址和端口不会重复导入

连通性 ​

面板每 3 分钟检测一次导入的节点能不能连上，结果显示在卡片上；导入的节点没有 agent，所以只有这种从面板发起的检测，没有到各地测试点的延迟。详见 延迟与回程 - 连通性检测。

对接中转 ​

导入后的节点和面板部署的入站一样：点击节点 → 中转 → 选择隧道即可，端口转发和隧道转发（包括经 IX 的多跳）都可以用。见 对接中转。

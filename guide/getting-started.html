快速上手 ​

用一台服务器搭一个 VLESS Reality 节点，经中转服务器对接，最后用订阅导入客户端。先了解名词可以看 基本概念。

1. 安装面板 ​

bash
curl -L https://github.com/kure29/flyx/releases/latest/download/panel_install.sh -o panel_install.sh && chmod +x panel_install.sh && ./panel_install.sh

选 1. 安装面板，完成后访问 http://服务器IP:6366，默认账号 admin_user / admin_user，登录后立即修改密码。

详见 安装面板。

2. 添加服务器 ​

  1. 设置 → 基本 里填好“面板后端地址”（服务器用它连接面板）
  2. 服务器 页新建两台服务器（一台搭节点、一台当中转），点 安装 复制生成的命令，到对应服务器上以 root 执行
  3. 等服务器状态变为 在线

详见 安装 agent。

3. 搭建节点 ​

  1. 服务器 页 → 内核 标签 → 安装内核，在搭节点的服务器上安装 Xray
  2. 节点 页 → 入站 标签 → 新建入站 → 选这台服务器和 Xray → 点模板 VLESS + Reality + Vision → 创建并下发

想知道该选哪个内核、哪个协议，见 内核与协议；入站的更多选项见 新建入站。

4. 对接中转（可选） ​

  1. 中转 页 → 隧道 标签新建隧道，入口选中转机
  2. 中转 页 → 线路 标签，点节点 → 选这条隧道（也可以在节点页点入站 → 中转）

详见 对接中转。已有别处搭好的节点，可以用 导入节点。

5. 导入客户端 ​

订阅 页里默认有一个“我的订阅”，点开它选客户端一键导入（Clash、sing-box、Shadowrocket、Loon、Quantumult X、Surge、Stash），或复制链接。直连和中转线路都在里面。

想按地区拆分、改名或分给朋友，见 订阅与客户端。

6. 看延迟（可选） ​

设置 → 延迟测试点 点 添加三网推荐，服务器就会定时测到北京 / 上海 / 广东三网的延迟，并检测回程线路（CN2 GIA、9929、CMIN2 等），结果显示在节点和服务器卡片上。详见 延迟与回程。

复制失败？

浏览器只在 HTTPS 页面里完全开放复制功能。建议给面板配置域名和 HTTPS，见 安装面板 - 反向代理。
